## Patch details

### `F08-unlock`

- bank 12 0x68ad: 64 02 -> e4 00  (APCS command entry: replace `xrl a,#2` with `clr a; nop`, so the following `jnz` never skips the request)
- bank 12 0x68bd: b4 02 14 -> e4 00 00  (AOCS command entry: replace `cjne a,#2,0x68D4` with `clr a; nop; nop`, so it always falls through)

### `F08-care`

- bank 12 0x68ad: 64 02 -> e4 00  (APCS command entry: replace `xrl a,#2` with `clr a; nop`, so the following `jnz` never skips the request)
- bank 12 0x68bd: b4 02 14 -> e4 00 00  (AOCS command entry: replace `cjne a,#2,0x68D4` with `clr a; nop; nop`, so it always falls through)
- bank 13 0xcaa8: 94 04 -> 94 02  (APCS interval 4 h -> 2 h (`subb a,#4` -> `subb a,#2`))
- bank 13 0xcad3: 7c 05 7d dc -> 7c 02 7d ee  (AOCS divisor 1500 h (0x05DC) -> 750 h (0x02EE))
- bank 13 0xcb1a: 94 24 -> 94 0c  (panel-care reminder 36 h -> 12 h (`subb a,#0x24` -> `#0x0C`))

### `F08-quiet`

- bank 12 0x68ad: 64 02 -> e4 00  (APCS command entry: replace `xrl a,#2` with `clr a; nop`, so the following `jnz` never skips the request)
- bank 12 0x68bd: b4 02 14 -> e4 00 00  (AOCS command entry: replace `cjne a,#2,0x68D4` with `clr a; nop; nop`, so it always falls through)
- bank 13 0xcaa8: 94 04 -> 94 24  (APCS interval 4 h -> 36 h (`subb a,#4` -> `subb a,#0x24`), matching the public F08b popup fix)

## What the patches do

- `unlock_cmd_gate` removes the `0xCFDE == 2` check in front of the
  APCS and AOCS command entries in bank 12. Those entries are the
  cleanest way to request a refresh; the check makes them inert when
  the command code is not 2.
- `apcs_2h` changes the automatic APCS interval from 4 h to 2 h.
- `apcs_36h` changes the automatic APCS interval from 4 h to 36 h
- `aocs_750h` changes the automatic AOCS interval from 1500 h to 750 h.
- `tss_12h` changes the panel-care reminder from 36 h to 12 h.

## Before flashing

1. Confirm the original image still matches
   `d4324c6c88abea48b1ee896f7e14ee9f`.
2. Read `firmware/PATCHED/README.md`.
3. Use the same OSD Sidekick version and USB 2.0 port as for the
   original image. Do not interrupt power during the flash.
4. If the monitor does not come back, restore the original image with
   the same procedure (or the bootloader/recovery method for your unit).
